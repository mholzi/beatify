## 4.8.4-rc1 — One More Song

The last song of the night gets played, and the end screen holds still.

### 🎉 The end of the game

- A game could end without playing its last song, most often on Music Assistant, where a song takes a few seconds to start. Every round you set up is now played.
- On the end screen, phones kept jumping back to the top and the confetti ran again and again. The host was thrown out of picking the next playlist. All of that now happens once per game.

### 🎛 Intro rounds from the admin page

The "Start Round" box for an intro round faded out after two seconds and never took a click, so a host running the game from the admin page alone was stuck. It now stays until the round is started. Thanks to **@aenkieh** for the report.

### 🎵 Playlist repairs

Broken links are repaired in Wiesn Party Hits, NDW, Iconic Movie Songs and Disney Hits Deutschland. "Long Cool Woman" by The Hollies moves to 1971.
